# AFM classroom

Open **index.html** in Chrome or another modern browser. Keep this folder together so the linked deck, source papers and reading pages remain available. The classroom is local and has no sign-in, paid API or external hosting.

Begin with Lessons & challenges. Choose a lesson, attempt its question, then reveal a hint or teaching checkpoint. The 42-question library opens every original requirement and full exhibit set. In Question studio, save a written or spoken-answer note, confidence, an error and a retry date. Use Voice companion to prepare the current question for an existing Codex voice conversation.

Progress stays in the browser and can differ between a file view and a local preview. Use **Save progress backup** before changing browser, moving devices or clearing browser data. **Restore backup** merges saved records into the current browser. The CSV is an independent printable tracker and does not synchronise automatically.

## Contents

- `materials/AFM-learning-deck.pptx`: 44 editable teaching/workshop slides. Worked checkpoints and source references are in speaker notes.
- `materials/study-plan.html`: eight focused hours Saturday–Wednesday, optional ninth hour, lighter Thursday.
- `materials/cheat-sheets.html`: eight concise method references.
- `materials/coverage-matrix.html`: all 42 questions and their scheduled exposure.
- `materials/question-guide.html`: original requirements and staged teaching routes.
- `materials/voice-tutor.html`: adaptive tutor workflow and continuity prompt.
- `materials/answer-sources.html`: verified and unverified answer links, with provenance.
- `papers/`: unchanged Markdown copies and readable HTML versions of all fourteen source papers.
