# AFM classroom authoring record

These files preserve the source extraction, lesson writing and deck generation from 5 September 2026. They record the original authoring environment and absolute paths; they are not part of the website build. Do not run them against the live public folder without adapting those paths and preserving the hosted integration.

The maintained deployable classroom is `public/afm-classroom/`; its 14 Markdown source papers are unchanged copies of the supplied files. The React entry is `src/pages/Classroom.tsx`. The standalone ZIP preserves the original local classroom and its local voice paths. Public voice prompts use hosted links with a paste fallback.

The deck validation receipt covers package structure and first-party import. All 44 rendered slides were also individually inspected. Native PowerPoint execution was not tested. Full official solutions remain incomplete; consult `public/afm-classroom/materials/answer-sources.md` for exact coverage and attribution.
